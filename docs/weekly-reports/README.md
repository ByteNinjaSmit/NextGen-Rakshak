## How this relates to the other `docs/` material

- [`docs/week-2/`](../week-2/README.md) and [`docs/week-3/`](../week-3/README.md)
  are a *different* kind of document: deep, per-member technical design and
  build write-ups for Weeks 2–3 specifically. These weekly-assessment files
  are the short, guide-signed department form for *every* week instead —
  they summarise the same work at a much higher level, plus cover Weeks 1
  and 4–9, which have no separate technical write-up folder.
- The project's black book (`reports/black_book.tex`) reproduces this same
  9-week log as a single table in **§4.1.3 "Weekly Progress Log
  (Guide-Assessed)"**, and cross-checks it against the Git commit history in
  **§4.1.2 "Version Control and Commit History"** — both arrive at the same
  conclusion: the system was fully built and tested within these 9 weeks,
  with final integration complete by 15 September 2026.
- Figures reported mid-project (e.g. Week 6's 36-pair accuracy trial) are
  the *raw field numbers from that week*. Where a later, re-verified
  measurement superseded them, the black book's §7.3.3 is the authoritative
  version — these weekly files are left as originally filed, not edited
  retroactively.
