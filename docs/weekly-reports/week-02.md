## Work done:

This week the team focused on designing the system architecture based on the
research conducted in Week 1. The high-level architecture diagram was created,
defining the three core components: the Police Kiosk Portal (Next.js), the
Volunteer Android Application (Kotlin), and the Offline Mesh Network (Nearby
Connections). The interaction flow between these components was documented,
including how alerts propagate from the kiosk to volunteers via Firebase Cloud
Messaging, and how the multi-hop store-and-forward routing layer functions
offline.

The team also designed the UI wireframes for the Police Kiosk Portal and the
Volunteer Android Application. The database schema for Firebase Firestore was
planned, including collections for alerts, volunteers, matches, and user
roles. The technology stack selection was finalised and the communication
protocols between components were documented. This foundational design work
directly supports Objective 1 by establishing a clear blueprint for a system
that operates independently of unreliable internet infrastructure during the
critical "golden hour."
